# Better guidance is a shared effort.

The goal is to make this a useful, approachable resource for people working across the creative community. Different experiences and perspectives will help make it better.

## What would be useful?

Suggest a topic that needs clearer guidance, improve an existing page, or share a practical example that helps people understand an issue. Keep contributions constructive, clear and respectful.

## How to contribute

The intention is to keep these pages as Markdown files in a GitHub repository. Once the repository is set up, contributors will be able to propose changes there for review.

The contribution process and repository link will be added once they are ready.
